Five directions

Five radically different takes on the landing page — design, positioning, and copy. Open each full-screen, note what earns its place, and we combine the best bits.

01

Gallery Light

"Systems built properly, by one person you can name."

code.storage's light mode studied properly: white ground, hairline rules, editorial numbered systems index, magazine contact form. Restraint does the selling.

motion: twisting wireframe column sculpture open →
02

Machine Dark

"I build the machine. You run it."

Warm near-black world where the hero's co-star is a living isometric factory: blocks ride a conveyor, get stamped into refined blue, and assemble into a wall that ships. The metaphor carries the positioning.

motion: deterministic isometric factory loop open →
03

The Operator's Letter

"You're not hiring an agency. You're hiring a person you can name."

The anti-landing-page: a single typeset letter on warm paper, fountain-pen blue, work shown as a ruled ledger inside the letter, one quiet ask — write to me. Filters out bake-off shoppers on purpose.

motion: opening line composes itself; signature hand-draws open →
04

Systems Catalog

"Pick a system. I install it in your business."

The library IS the site: nine systems as numbered precision instruments (MR-01 … TD-09) with FOR / REPLACES / OUTPUT spec rows and status stamps, on graph paper. Working light/dark toggle.

motion: exploded-view assembly, 9s mechanical loop open →
05

Proof Ledger

"The books don't lie. Your delivery platforms might."

Evidence aesthetics: real anonymized numbers as audit exhibits (40,803 orders reconciled; 9,039 outage events), NDA redaction bars where figures are private, terms as a stamped invoice. Talks money openly.

motion: thermal receipt prints line-by-line, stamps RECONCILED open →

Each page is self-contained and safe to open full-screen. All five: no yellow, no green, no internal strategy in the copy, reduced-motion respected.
